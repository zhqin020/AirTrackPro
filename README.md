# AirTrack Pro - 无线智能触控板与控制生态系统

AirTrack Pro 是一款将智能手机转变为低延迟无线多功能触控板与键盘的系统，旨在提供跨设备、极低延迟的远程物理与仿真计算机控制解决方案。

本系统支持**浏览器仿真联动测试**，同时也支持通过轻量级的 **Python 真机控制引擎**将手势、打字、快捷键及画板同步到任何真实的 Windows、macOS 或 Linux 操作系统。

---

## 🌟 核心功能模块

### 1. 📱 移动控制端 (Smartphone Client)
- **高精度无线触控板 (Touchpad Area)**：支持手指滑动、单击（模拟鼠标左键）、双击（模拟鼠标右键）、双指或 `Shift + 拖动`（模拟滚轮滚动）。实时渲染多点触控视觉涟漪。
- **普通键盘 (Standard Keyboard)**：提供完整的 QWERTY 键盘，支持字母、空格、回车、退格等键，支持本地缓冲与瞬间发送。
- **扩展键盘 (Extended Keyboard)**：内置功能键（Esc, Tab, Fn, NumLock）、F1-F12 快捷键、全向方向键、常用小键盘（Numpad 0-9, ., +, -, *, /）以及垂直的回车 Enter 键，适合专业办公与多媒体娱乐。
- **高精细度参数配置**：
  - **跟踪速度与滚动速度**（1x - 10x 自由调节）。
  - **自然滚动方向**开关。
  - **左手模式**（翻转鼠标主副键与控制布局，适合左撇子或特殊人群）。
  - **点击振动/音效反馈**、**防止屏幕休眠**、**触摸轨迹显示**。
- **快速系统组合键**：一键呼出 Windows 任务管理器（`Ctrl+Alt+Del`）或瞬间显示桌面（`Win+D`）。

### 2. 💻 电脑接收端 (PC Receiver Portal)
- **配对与状态控制台**：动态生成 4 位随机/固定安全配对码 PIN，实时显示当前连接延迟（精确到 0.1 毫秒）与数据包传送统计。
- **多窗口 Windows 11 仿真桌面**：
  - **配对与状态控制台**：管理连接、手动输入或自动匹配局域网内网 IP，并生成快速扫码链接。
  - **电子手写画板**：配备绿/蓝/红/黄多色画笔，支持“悬停绘图”功能，实现流畅的手势书写或涂鸦。
  - **记事本演示**：提供即插即用的文本输入测试框，测试物理手机打字的输入流畅度。
  - **数据包实时终端**：以终端日志方式打印极细致的 WebSocket 状态和原始控制字节流，方便排查与开发调试。

### 3. 🐍 Python 真机物理接收程序 (Physical Controller)
- 利用 `pyautogui` 与 `websockets`，将浏览器接收到的动作完美翻译为**物理电脑系统的真实指针事件**。
- 真正控制整个操作系统的鼠标指针、滚动、单击、双击、快捷键和任何复杂文本输入。

## 🚀 局域网配对与操作说明

### 1. 仿真联动测试（双端联动）
1. 在浏览器中打开 AirTrack Pro 主页。
2. 默认进入**双端联动测试模式**（左侧为手机端，右侧为电脑接收端）。
3. 确保两端的 PIN 码一致（默认 `1111`），手机端点击“连接”即可开始操作。
4. 在手机触控板上滑动，可以看到右侧电脑端的鼠标光标同步移动，可以在右侧记事本中打字，或在画板上画画。

### 2. 手机真实扫码控制电脑
1. 电脑端打开 AirTrack Pro 页面，并将其设置为“电脑接收端”视图。
2. 控制台会自动检测您当前电脑的局域网内网 IP。如果未检测到或检测不准，可在控制台点击“手动输入”填入您电脑的真实局域网 IP（例如 `192.168.31.100`）。
3. 确保您的**手机和电脑连接在同一个 Wi-Fi 网络（局域网）下**。
4. 手机扫描电脑页面上生成的二维码，手机浏览器中将自动加载全屏、无多余外框、无工具栏遮挡的专业版手机控制端。
5. 手机端输入电脑屏幕上的 4 位 PIN 配对码，点击“连接”即可体验无线控制。

### 3. 连接真实实体电脑（控制您的实际操作系统）
如果您希望使用手机控制当前的实体 Windows/macOS/Linux 电脑，而不仅仅是浏览器内的仿真桌面，请按照以下步骤操作：

#### 步骤 1: 在您的真实电脑上安装 Python 依赖
打开您的终端（Terminal）或命令提示符（CMD/PowerShell），执行以下命令安装接收端库：
```bash
pip install pyautogui websockets asyncio
```

#### 步骤 2: 保存并运行物理接收端脚本
1. 在电脑端的“连接实体电脑”模块中，点击 **“复制 Python 脚本”** 按钮。
2. 在您的真实电脑中新建一个文本文件，命名为 `receiver.py`，并将复制的代码粘贴进去。
3. 在终端中运行该 Python 脚本，命令行参数需指定您在网页上看到的 PIN 和服务端地址：
   ```bash
   python receiver.py --pin <您的4位PIN码> --server <电脑端页面显示的局域网地址>
   ```
   *例如：`python receiver.py --pin 1111 --server http://192.168.1.5:3000`*

#### 步骤 3: 体验全系统物理操控
此时用手机浏览器扫码（或已连接的手机端），您在手机触控板上的滑动和在键盘上的打字，将直接变为您真实物理电脑上的鼠标、打字和滚轮操作！

## 🛠️ 技术内幕与协议规范

### 1. 极低延迟网络架构
本系统利用全双工 **WebSocket 协议** 进行数据传输，省略了传统 HTTP 轮询的额外握手和体积。
- **指令格式**：使用紧凑、高度优化的 JSON 数据包进行数据承载，每个数据包的大小控制在 100 字节以内。
- **事件过滤**：手机端在移动时对频繁的滑动动作进行了适当的微秒级防抖与采样率控制，在保障灵敏度的同时避免了网络拥堵。

### 2. 数据包格式规范
- **光标移动**：
  ```json
  { "type": "move", "dx": -12.5, "dy": 4.2 }
  ```
- **按键点击**：
  ```json
  { "type": "click", "button": "left", "action": "click" }
  ```
- **滚轮滚动**：
  ```json
  { "type": "scroll", "dy": -3 }
  ```
- **键盘按键**：
  ```json
  { "type": "key", "key": "A" }
  ```
- **系统快捷键**：
  ```json
  { "type": "shortcut", "keys": ["ctrl", "alt", "delete"] }
  ```

## 🎨 视觉与体验设计

- **磨砂玻璃与深邃极客蓝配色**：采用高对比度、防眩光的 `#0A0C10` 极夜黑和 `#0F1117` 极客深蓝背景，保护两端在长时间极客调试和暗光下的用眼健康。
- **触控板弹性阻尼感**：优化了滑动时的惯性参数与移动缩放公式，让指针在大屏幕上的控制更加丝滑、指哪打哪。
- **Windows 11 多窗口模拟器**：支持完美的层级叠加（Z-Index 动态提升）、双击窗口标头置顶、流畅的展开/收起过渡动画，提供无缝、好玩的拟真式操作系统桌面体验。
